A puzzle with a twist

Think about
the whole board.

Each direction moves every orb at the same time. Walls, edges and other orbs change where each one stops. A move that helps one orb can reposition another.

Read the board, look for useful blocks, then guide every color to its matching goal. Easy to pick up. Satisfying to solve.
